# Tải tất private Cobalt API

This service is intended for the Tải tất Cloudflare Worker only. It requires
an API key from the private key file endpoint and uses authenticated API calls.
Do not set API_AUTH_REQUIRED=0 or publish the API key in the frontend.

The instance uses upstream Cobalt v11. Its source extractors support public
media only. Upstream service support and availability can change at any time.
